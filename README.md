# VaaniSetu – AI For All

## About the Project
VaaniSetu is an offline-first AI communication web application developed by the AesterAI Team. It provides a zero-cost, privacy-first communication solution tailored specifically for the 2.7 crore Indians living with acquired speech disabilities. 

## Key Features
* **Offline Functionality:** The application is 100% offline ready, ensuring continuous accessibility without internet dependence.
* **Quick Phrases:** Users can quickly tap pre-saved phrases across categories like basic needs and feelings to speak them aloud instantly.
* **Live Speech Transcription:** A live typing interface converts text directly into natural voice speech.
* **Emotion Recognition:** Users can express their current feelings with emotional tone control and custom speech.
* **AI Voice Cloning:** Features the ability to create, test, and preserve personal voice profiles and accents.
* **Gesture Cards:** Designed for semi-literate or elderly users, this feature allows users to point a camera at cards to speak without typing, powered by MobileNetV3 recognition.
* **Emergency SOS:** Includes a dedicated safety feature to instantly alert pre-saved emergency contacts.

## How to Run
Since this application is built using standard web technologies (HTML, CSS, JavaScript), there is no complex installation required.

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser to launch VaaniSetu.
