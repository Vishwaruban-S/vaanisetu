# VaaniSetu – AI For All[cite: 1]

## About the Project
VaaniSetu is an offline-first AI communication web application developed by the AesterAI Team[cite: 1]. It provides a zero-cost, privacy-first communication solution tailored specifically for the 2.7 crore Indians living with acquired speech disabilities[cite: 1]. 

## Key Features
* **Offline Functionality:** The application is 100% offline ready, ensuring continuous accessibility without internet dependence[cite: 1].
* **Quick Phrases:** Users can quickly tap pre-saved phrases across categories like basic needs and feelings to speak them aloud instantly[cite: 1].
* **Live Speech Transcription:** A live typing interface converts text directly into natural voice speech[cite: 1].
* **Emotion Recognition:** Users can express their current feelings with emotional tone control and custom speech[cite: 1].
* **AI Voice Cloning:** Features the ability to create, test, and preserve personal voice profiles and accents[cite: 1].
* **Gesture Cards:** Designed for semi-literate or elderly users, this feature allows users to point a camera at cards to speak without typing, powered by MobileNetV3 recognition[cite: 1].
* **Emergency SOS:** Includes a dedicated safety feature to instantly alert pre-saved emergency contacts[cite: 1].

## How to Run
Since this application is built using standard web technologies (HTML, CSS, JavaScript), there is no complex installation required.

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser to launch VaaniSetu.
